# Every Kakeya set in F_3^5 has at least 41 points (computer-checked moment bound)

This file is committed only together with `test_kakeya_moments_f35.py`, and the publish step

N <= 40 and requires each to be infeasible.

## Claim

k_5, the smallest size of a Kakeya set in F_3^5, is at least 41. The best lower bound we found in
print is 32 (Bukh-Chao: 243 / (5/3)^4 = 31.5). The smallest set known has 53 points (Lev's
recurrence prediction, constructed by Chung, Du and Wesley, arXiv:2608.23691, and by the Dualverse
notebook).

## Method

The same as `README.md` (F_3^4), with the AG(5,3) flat counts: 121 hyperplane classes of 3, 40
hyperplanes through a line, 13 through an affine plane. Condition (T): sections of one class
pairwise multiply to at least 81. Identities: the sum of C(n_H, 2) over the 363 hyperplanes is
40 C(N,2), and the sum of C(n_H, 3) is 13 C(N,3) + 27 L with L >= 121 lines.

Hand certificate for the largest excluded case, N = 40: with c = 13.9, the largest value of
10 s3 - 139 s2 over the allowed profiles is -24973, at the most balanced profile (13,13,14)
(10 * 936 - 139 * 247). Summing over the 121 classes gives
10(128440 + 27L) - 139 * 31200 <= 121 * (-24973), so L <= 113, while L >= 121 is needed.
Smaller N are excluded by the script in the same way (exact integer arithmetic).

## Limits
